Node Js is BasICALLY JAVAscript Running on our Machine rather than browser

nodeJs -> V8 Engine + Cpp 

npm -> Node package manager

Running Node JS:
Command 
  -> npm init (In the Folder You want to run it)
we will get a package.json as a configration file

In package.json file you can define your Own Scripts for a Specfic commmand
 e.g.   "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1",
    "start": "node hello.js" 
  }



module.exports & require() Functions in Node Js

[

Using Other Files Inside The main File:
  const math = require('./math.js');
or const {addfn , subfn} = require('./math.js');
where math.js was the file we Were Importing things form  

Inside The math.js we need to Export things ()
Thorugh module.exports
module.exports is BasICALLY returning all the file's attachments as an object

i.e.


module.exports = {
   addfn: add,    
   subfn: subtract
}
(Where Add and sub Are the functions Inside the Math)


console.log(math.addfn(52, 48));
Which Gives 100
